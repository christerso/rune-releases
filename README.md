# Rune

Rune is a script language for builds, tests and deployments, from Antisoftworks. Home page: https://antisoftworks.com/rune

Rune runs commands without a shell, checks a whole script before its first line runs, stops at a failed command and rebuilds only what has changed. It replaces the bash and ksh scripts that builds and deployments tend to collect.

## Download

- Windows: from the Microsoft Store. It adds the `rune` command to every terminal.
- macOS: the signed and notarised installer for Apple silicon, from https://antisoftworks.com/rune
- Linux: the .deb and Arch packages, and a tarball for servers, from https://antisoftworks.com/rune

Current release: 1.0.1. Rune also comes with AntiTerm, the Antisoftworks terminal.

## Licence

Free to use, including commercially. The source code is not published.

## Reporting a bug

Run `rune report bug "what happened"` to send a bug report in one command. Rune also reports its own crashes.

## About this repository

This repository holds release files only: the installers and packages for each version, with their notes. It holds no code.
